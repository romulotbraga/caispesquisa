# CAIS · Coleta de campo

Site da pesquisa de implementação do CAIS (caispesquisa.netlify.app). Páginas estáticas, sem etapa de build, com os dados no Supabase.

- `index.html`: abas Coleta, Banco de dados e Painel.
- `encaminhamentos.html`: mapa de encaminhamentos.
- `cais-db.js`: acesso ao banco, usado pelas duas páginas.
- `supabase/001_inicial.sql`: estrutura e regras de acesso do banco.
- `CONTEXTO.md`: estado do projeto, decisões e pendências. Leia antes de mexer.
